This project presents a comprehensive mathematical modeling solution for optimizing emergency evacuation procedures within buildings. Developed for the HiMCM 2025 competition, our model integrates greedy algorithms, dynamic programming solutions, and real-world scenario implementations to enhance evacuation efficiency and safety.
We attempted to use the Three.js library for interactive 3D modeling to visually represent building layouts and evacuation data. Due to time constraints and technical challenges, this section is still under development, but its potential is significant.
